# To-Do List

A simple to-do list built using plain HTML, CSS, and JavaScript.

This project was made to practice core frontend concepts like DOM manipulation, event handling, and basic state management — without using any frameworks.

## Features
- Add tasks
- Mark tasks as completed
- Delete tasks
- Add tasks using the Enter key

## Tech
- HTML
- CSS
- JavaScript (vanilla)

## Why this project
Built as part of learning JavaScript fundamentals before moving on to API-based projects.

## Future ideas
- Save tasks using localStorage
- Animations
- Multiple lists
